# مدرسه هوش مصنوعی یاس — اسکیل دستیار طراح استایل‌های اسلاید NotebookLM
گردآوری و پشتیبانی توسط **جعفر قربانی** / **مدرسه هوش مصنوعی یاس**.

- **مخزن پروژه:** [https://github.com/hvrashta/nps](https://github.com/hvrashta/nps)

این پوشه شامل منطق و ساختار استاندارد اسکیل **استایل‌های اسلاید NotebookLM** مدرسه هوش مصنوعی یاس است. این اسکیل طراحی شده تا هر کتابچه برند، تصویر، یا مودبورد را به پرامپت استاندارد YAML تبدیل کند تا NotebookLM بتواند اسلایدهای هماهنگ و چشم‌نواز تولید کند.

## این اسکیل چیست؟
این یک پرامپت ساختاریافته (شناخته‌شده به عنوان Skill یا Workflow) است که می‌توانید آن را به دستیار هوش مصنوعی خود (مانند Claude، ChatGPT و غیره) اضافه کنید تا توانایی تخصصی طراحی اسلاید برای NotebookLM را به دست آورد.

## محتویات
- `SKILL.md`: ساختار منطقی اصلی و اسکیما استانداردهای YAML.
- `README.md`: این فایل راهنما.

## نحوه استفاده توسط توسعه‌دهندگان
اگر در حال توسعه یک عامل هوشمند (Agent) یا ابزاری هستید که نیاز به تولید طراحی‌های سازگار با NotebookLM دارد:
۱. محتوای فایل `SKILL.md` را در System Prompt دستیار خود قرار دهید.
۲. یک ورودی بصری (تصویر، لوگو، کتابچه هویت بصری) به آن ارائه کنید.
۳. هوش مصنوعی یک کد استاندارد و معتبر YAML تولید می‌کند که کاربران می‌توانند آن را مستقیماً در بخش Custom Instructions ابزار NotebookLM الصاق کنند.

## نکته یکپارچه‌سازی
هنگام استفاده از این اسکیل، مطمئن شوید هوش مصنوعی روی **سلسله‌مراتب بصری (Visual Hierarchy)** و **کنتراست** تمرکز کند، چرا که موتور تولید اسلاید NotebookLM بر پایه توصیفات دقیق، عناصر را روی اسلاید جانمایی می‌کند.
