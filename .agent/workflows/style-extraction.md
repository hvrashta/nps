# فرآیند کاری: استخراج و مستندسازی استایل‌ها

این پروتکل استاندارد استخراج سیستم‌های طراحی بصری از مراجع و یکپارچه‌سازی آن‌ها در مخزن استایل‌های اسلاید مدرسه هوش مصنوعی یاس را مشخص می‌کند.

- **آدرس مخزن:** [https://github.com/hvrashta/nps](https://github.com/hvrashta/nps)

## ۰. پیش‌نیازها و بستر
قبل از هر اقدامی، عامل هوشمند **باید** فایل `README.md` را بررسی کرده و فایل‌های پوشه `styles/` را کاوش کند:
- شناسایی ۶ دسته‌بندی اصلی: تجاری، مینیمال، خلاقانه، مجلاتی، فناوری و طبیعت.
- حفظ یکپارچگی در لحن و ساختار فرمت‌ها.
- نام استایل‌ها و ساختار کلیدهای YAML جهت سازگاری جهانی به صورت انگلیسی استاندارد حفظ می‌شود.

## ۱. استخراج استایل بصری
از اسکیل `notebooklm-slide-styles` به عنوان موتور اصلی استفاده کنید.
- **ورودی**: تصاویر، کتابچه برند یا توضیحات را به اسکیل ارائه دهید.
- **بررسی خروجی**: اطمینان حاصل کنید ساختار خروجی YAML تمام جزئیات پالت رنگ و تایپوگرافی را پوشش می‌دهد.
- **تصاویر**: تصاویر پیش‌نمایش به صورت خودکار ایجاد نمی‌شوند، بلکه اسکرین‌شات‌های واقعی نوت‌بوک جایگذاری می‌شوند.

## ۲. ایجاد فایل استایل
یک فایل `.yaml` جدید در پوشه `styles/` ایجاد کنید.
- **نام‌گذاری**: از ساختار ساده `snake_case` استفاده نمایید (مثال: `scholars_journal.yaml`).
- **کامل بودن**: حتماً بخش‌های `image_generation_prompts` و `slide_layout_templates` را تکمیل کنید.

## ۳. مستندسازی در README.md
استایل را با استفاده از اسکریپت خودکار در `README.md` ثبت کنید:
- **دستور**: `node scripts/add-style.js --name "Style Name" --cat "Category" --yaml "styles/filename.yaml"`

## ۴. همگام‌سازی داده‌ها
**اجرای این دستور الزامی است** تا سایت گالری بلافاصله تغییرات را نمایش دهد:
```bash
npm run build:data
```

## ۵. دستورالعمل گیت
- **فرمت کامیت**: `feat (Styles) - Add [name style] style`
- ثبت تغییرات فقط پس از تأیید و درخواست کاربر انجام گیرد.

## ۶. بررسی نهایی
- اجرای `npm run build:data` جهت تطبیق کامل ساختارها.
- اطمینان از سلامت خروجی و عدم وجود مغایرت در پیوندها.
